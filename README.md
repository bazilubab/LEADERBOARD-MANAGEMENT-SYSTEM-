## ⚡ Dynamic Capabilities

The system runs on an interactive loop, providing users with the following core operations[cite: 13]:

```diff
+ [ 1 ] Add Player: Register a new profile with a unique ID, Name, and Score.
- [ 2 ] Delete Player: Wipe a player's record from existence using their unique ID.
# [ 3 ] Display Leaderboard: Render the complete, tabulated matrix of all active players.
! [ 4 ] Sort by Score: Re-organize the entire board in descending order using Bubble Sort.
@@ [ 5 ] Search Player: Pinpoint specific player statistics instantly via Linear Search. @@
